# Assist (French text assistant) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nidoo understands short French sentences about lights, heating setpoints and temperatures, typed on a web Assistant page, and acts or answers safely.

**Architecture:** A new pure crate `nidoo-assist` (no I/O, wasm-buildable) parses a sentence and plans against a borrowed snapshot of the house (areas, entity views, climate zones). The hub module `crates/nidoo/src/assist/` builds the snapshot, executes plans through `Hub::send_command` / `Hub::set_climate_override`, keeps one pending question per client and a turn log (DB when available, memory always). The web gets an `/assistant` screen and a floating button linking to it.

**Tech Stack:** Rust 2024 workspace, axum (hub HTTP), sqlx/Timescale (optional DB), Leptos-style wasm web (`nidoo-web`), serde/schemars.

**Spec:** `docs/superpowers/specs/2026-11-02-assist-design.md`

## Global Constraints

- `nidoo-assist` is pure: no I/O, builds for `wasm32`, deps serde/serde_json, optional `schemars` feature, like `crates/nidoo-alarm/Cargo.toml`.
- No device-, house- or person-specific word in code, tables or tests; test fixtures use fictional rooms (Salon, Bureau, Chambre Léa, Chambre Tom, Garage).
- Hub executes only through existing paths: `Hub::send_command`, `Hub::set_climate_override`, existing views.
- Version 1 intents only: lights on/off, heating setpoint, temperature reading. No LLM, no shortcuts, no English parsing.
- Heating safety range default **16–23 °C**; ask when outside it or more than **3 °C** from the zone's current reading.
- "monte"/"baisse" without amount, or "un peu" = **0.5 °C**.
- One pending question per client, expires after **60 s**.
- Turn log: DB table purged after **90 days**; memory ring of the last **100** turns.
- Replies are French and always name room + action + value; numbers use a decimal comma and drop ",0" ("18,2 °C", "20 °C").
- CI must pass: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo check --target wasm32-unknown-unknown -p nidoo-assist -p nidoo-web`, web `bare_text` guard.
- Commits as Gekkotron: `git -c user.name=Gekkotron -c user.email=60887050+Gekkotron@users.noreply.github.com commit …`, message ending with the `Co-Authored-By` / `Claude-Session` lines. Build with `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0`.

## Review Focus

1. **On/off never inverted by a typo**: "étein", "allumme", "eteint" (past participle used as an order). Expected: the right verb or "pas compris", never the opposite. Test in Task 2.
2. **A number that is not a setpoint**: "allume les 3 lumières du salon", "mets le salon à 20 % " (brightness, out of scope). Expected: never a heating action; lights act or "pas compris". Test in Task 6.
3. **Room names that contain each other**: areas "Salon" and "Salon TV"; "salon" must pick "Salon" (exact beats substring), "salon tv" must pick "Salon TV". Test in Task 3.
4. **Pending question then an unrelated sentence**: after "Quelle pièce ?", typing "il fait combien dehors ?" answers that and drops the pending question; a late "oui" after expiry does nothing. Test in Task 9.
5. **Simulation never touches the house**: every outcome with `simulate: true` publishes nothing and the reply starts with "Simulation :". Test in Task 9.
